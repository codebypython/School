## 3. QUY TRÌNH PHỐI HỢP & TÁC NGHIỆM CỦA HỌC VIÊN

1. **Sprint Planning**: Bóc tách User Stories theo chuẩn INVEST, chấm điểm Story Points bằng Planning Poker.
2. **Daily Collaboration**: Phân nhánh Git theo Feature Branch, commit theo chuẩn Conventional Commits.
3. **Pull Request & Code Review**: Mở PR, yêu cầu Review Checklist và chỉ merge khi CI build & tests pass 100%.
4. **Sprint Retrospective**: Đánh giá Sprint qua 3 câu hỏi: Cái gì làm tốt? Cái gì chưa tốt? Cần cải tiến gì?
