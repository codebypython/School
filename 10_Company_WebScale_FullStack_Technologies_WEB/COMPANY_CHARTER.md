1. **Nắm bản chất JS/TS**: Hiểu Call Stack, Web APIs, Macrotask/Microtask Queue và cơ chế suy luận kiểu TypeScript.
2. **Xây dựng Backend trước**: Dựng API chuẩn RESTful/GraphQL bằng NestJS với đầy đủ DTO validation, authentication và unit tests.
3. **Phát triển Frontend**: Xây dựng UI bằng Next.js App Router, kết nối SSR/CSR tối ưu hóa SEO và trải nghiệm người dùng (UX).
4. **Kiểm thử E2E & Triển khai**: Viết kiểm thử tự động bằng Vitest và Playwright trước khi deploy.
